# rezept-generator

## Arbeiten auf zwei Rechnern (Laptop + PC-Agent)
Dieses Repo bearbeiten Tobi auf dem Laptop (VS Code + Claude) und ein Agent auf dem PC. Gemeinsamer Stand ist nur, was auf GitHub liegt; Gespräche werden nicht geteilt.
- **Zu Beginn:** `git pull --rebase`, dann `STAND.md` lesen.
- **Zum Schluss** (auch bei Zwischenständen, bevor die Sitzung endet): `STAND.md` kurz aktualisieren (erledigt, in Arbeit, nächste Schritte, offene Fragen), committen und direkt auf `main` pushen. `STAND.md` im selben Push wie die Arbeit, keine Extra-Pushes nur dafür.
- Nichts ungepusht liegen lassen: Was nicht auf GitHub ist, sieht die andere Seite nicht.
- Nie Force-Push. Konflikte beim Rebase sorgfältig lösen, im Zweifel Tobi fragen.
